# W20 VOID-GATE DESK RECEIPT (2026-09-24)

Desk: VOID-GATE on amd/v340-port-v2. ZERO-GPU. Turns the adopted ledger E-133
operational rule ("a decision cell is VOID if die-3 sclk act-mean < ~1150 MHz
or <=991 MHz duty > 20 percent") into a runnable adjudicator for every banked
and future cell. Instrument: docs/amd-port/scripts/void_gate.py. Inputs are the
guard battery's own 5 s thermal sideband logs; nothing else.

## 1. WHAT IT COMPUTES

Per input log (auto-detected layout: guard CSV `timestamp,elapsed_s,cN_*` or
the W15 4-die plain-text `<epoch> <edge>C <sclk>MHz x4`), over the decode
window (auto: [10, 95] s for cells with wall > 120 s = battery shape, else the
last 25 s; `--whole` for steady-state traces; `--win-lo/--win-hi` to pin):

- per column group: sclk act-mean over loaded samples (> 500 MHz only - idle
  300 MHz boot samples are excluded), <=991 MHz duty fraction, min sclk;
- verdict from the die-3 group per E-133: VOID iff act-mean < 1150 MHz OR
  <=991 duty > 20 percent (thresholds overridable via --act-mean-thresh /
  --duty-thresh).

Exit codes: 0 all cells PASS, 1 a DECISION cell is VOID, 2 any cell
unadjudicable (UNSUPPORTED / NODATA / NOCLKS - reported explicitly, never
guessed). `--observe` reports verdicts without gating the exit code on VOID.
`--json` emits machine-readable output.

CARD CAVEAT (also in --help): column groups are CARD-indexed, not
die-indexed - the sampler (guard_battery.py ThermalSampler) hardcodes
rocm-smi card0/card1/card2. In the banked evidence set card0/1/2 == PCI
05:00/08:00/0D:00 == dies 1/2/3, so the die-3 default is the LAST group; for
the 4-die text layout (die-ordered) the default is group 2. After a boot that
reshuffles card order the default is wrong (card1 can become the NVIDIA
display GPU) - pin --die3-group. Die 4 (10:00) is never sampled in CSV logs;
per W15/W18 it throttles together with die 3, which stands in for the
far-die pair.

## 3. COORDINATOR INVOCATION (after each window, one line)

  python3 docs/amd-port/scripts/void_gate.py <cell>=/home/chris/<cell>_thermal.log

exit 0 -> bank the cell; exit 1 -> VOID, do not bank the decision (re-run the
cell at position 1 or after >= 5-10 min idle); exit 2 -> log format cannot
support the rule, adjudicate by hand. For a whole window's cells pass them all
in one command; any single VOID exits 1. Use --json for machine consumption.
