2. FINDINGS (mechanisms, each measured)
===========================================================================================
FINDING 1 — the ar bracket drops the mixer AR (accounting, not waste):
  OPTRACE ar column = 60.3 ms/chunk but nccl device busy = 119.5 ms (2.0x). VerifyLayerTrace
  holds ONE ar event pair per layer (ev_ar[layer][slot][0/1]); BOTH per-layer allreduces call
  vt.ar_begin/ar_end (mixer: attn o-proj :2603-2605 and gdn out :3013-3016; mlp: mlp_tail
  :3219-3221). The mlp site RE-RECORDS ev_ar[..][0], so the pair times only the MLP AR; the
  ~64 mixer ARs/chunk (~59-60 ms) fall outside every bracket -> P1's body = window − gemm −
  ar absorbs them -> unbr prints them. EXCERPT (per-layer device sequence, one GDN layer):
    axpy 8us | rmsnorm 14.8us | gating 213us | tiled<80> 2869us | unpack 27 | conv 41 |
    gbet 8 | dn(l2,wy,sp,out) 657 | gnorm 9 | tiled<24> 922 | NCCL 1010us | axpy |   <- mixer AR
    mnorm 14 | tiled<80> 5556 | silu 69 | tiled<68> 2522 | NCCL 726us | axpy           <- mlp AR (the only one timed)
  Fix = instrumentational (2 pairs/layer or per-AR slots); zero wall ms; restores honest
  attribution (ar 60 -> ~120) and re-premises the AR floor desk (see fixes).

FINDING 2 — the per-chunk pageable-H2D enqueue stall (real waste, the cure target):
  Per chunk EACH rank thread (4/4 identical; 16 giant blocked calls each over the prefill)
  issues small pageable H2Ds whose HOST calls block ~the full chunk:
    hipMemcpyAsync cid281609: host block 991.5 ms; device transfer 3.7 us (~512 B);
      executes at chunk end (in-order stream drains; pageable staging cannot return until
      the DMA retires). Zero other API calls overlap the block (thread fully pinned).
    plus a medium 27.5-us H2D blocking the host 51-60 ms/chunk.
  Class = the CURED finalize bug (PLOG-055 "108-B staging size class", 659 ms -> 0.008),
  still live on the steady-chunk path: the 512-B size and the per-chunk cadence match the
  chunk-ids/worker-MTP-redo copy_i32 H2D class (copy_i32 = pageable memcpyAsync wrapper,
  text_context_impl.h :57-64; call sites :3598 chunk ids, :3883 legacy mtp ids; the
  TAIL_ASYNC device recipe removed it only from the finalize tail).
  Consequences (measured): all launches land in one ~65 ms burst; the compute queue runs
  ~1 chunk deep and thin -> 618 device micro-idles (14.3 ms/chunk, sync-class C) + a 15.5 ms
  host chunk-end sync (P1 gap col 17-24 ms is this + embed); fragility: any device hiccup
  drains the thin queue straight to the host stall.

   retires; on a ~1-chunk-deep in-order stream that is ~1 chunk of host stall per copy.
   Expected: the ~14.3 ms/chunk device idle closes (device then runs queue-fed end to end),

   1 — any compute hiccup serializes straight to the host). Serve-leg A/B NOT run: cure needs

   AR optimization target is honest.
